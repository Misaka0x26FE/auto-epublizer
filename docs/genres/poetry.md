# 诗歌与散文 · 翻译优化文档

> 诗歌与散文的专门优化规范。此类文体的核心是**形式承载意义**（分行、格律、韵脚、意象、节奏），
> 翻译不能只求字面忠实。

## 1. 文体定位与识别特征

识别特征：

- 诗歌：分行/分节、格律或自由体、韵脚、意象密集；
- 散文：随笔/小品，重意境与节奏，段落松散自由；
- 辅文极少：通常只有标题、正文、可选注释。

## 2. 结构特征与辅文侧重

| 区域 | 处理 |
|---|---|
| 标题 | 需译，简洁 |
| 正文（分行/分节） | 保留行结构与分节 |
| 注释（如有） | 保留双向跳转 |
| 献词/题记 | 需译 |

## 3. 分析维度（analyze 产出）

| 字段 | 含义 |
|---|---|
| `form` | 体裁（自由诗/格律诗/散文诗/随笔） |
| `meter` | 格律 / 音节 |
| `rhyme` | 韵脚 |
| `imagery` | 意象体系 |

## 4. 术语与实体表

- 通常较少专名；偶有人名/地名/典故需注。
- 若含典故/文化负载词，记入术语表 `type=term`，附 `note` 解释。

## 5. 翻译指引

1. **保留行结构与分行**（诗歌的生命线）；
2. **意象优先于字面**：为保意象可适度调整字面；
3. **韵脚策略显式声明**（关键取舍）：
   - `keep_meaning`：保意弃韵（推荐默认，可读性优先）；
   - `keep_rhyme`：保韵弃部分字面（格律诗可选项）；
4. 节奏与语感按目标语言自然表达，不机械逐字。

## 6. 审校侧重（映射 QC）

| QC 关卡 | 诗歌侧重 |
|---|---|
| G0 | 行数/分节一致（对照表完整性） |
| G1 | 侧重 `missing`（意象丢失）、分行错乱 |
| G2 | 取证：典故/文化负载词注释 |
| G3 | 意象/固定意象跨段统一 |

**宽容度**：诗歌翻译字面自由度大，审校只报**意象丢失、行结构破坏、明显误译**，不报措辞差异。

## 7. 特殊优化清单

- [ ] 行结构/分节保留（对照表按行对齐）
- [ ] 意象优先 + 韵脚策略声明
- [ ] 典故/文化负载词注释
- [ ] 审校 missing（意象丢失）+ 分行错乱检测
- [ ] 高宽容度（不报措辞差异）
