# Documentation i18n Policy / 文档国际化政策

This project ships every document in **two languages**: English (default, `X.md`) and
Chinese (`X.zh.md`). Chinese is the **authoritative source**; English is a derived
translation maintained by the agent (no runtime LLM calls — see the "single LLM"
principle in `AGENTS.zh.md`).

本仓库所有文档均为**中英双语**：英文默认（`X.md`），中文 `X.zh.md`。**中文为权威源**，
英文为派生译文（由 agent 维护，不新增任何 LLM 调用）。

## Naming / 命名

| Role | File name |
|---|---|
| English (default, shown by GitHub) | `X.md` |
| Chinese (authoritative source) | `X.zh.md` |

Both live side by side in the same directory. `docs/i18n.md` (this file) is the only
**bilingual single file** exception.

## Language banner / 语言横幅

Top of every translated pair:

```markdown
> **English** | [中文](X.zh.md)
```

```markdown
> **中文** | [English](X.md)
```

## Sync contract / 同步契约

The derived file (English) carries a stamp naming the source and its content hash:

```markdown
<!-- i18n: source=X.zh.md sha256=<64 hex> -->
```

The tooling is direction-neutral (it verifies whatever `source=` names), so the
authority may be swapped later by re-stamping.

```bash
python scripts/i18n.py --check              # stamps fresh + banners present
python scripts/i18n.py --links              # relative md links resolve + language-consistent
python scripts/i18n.py --relink X.zh.md     # point relative links at this language's siblings
python scripts/i18n.py --finalize X.md      # (re)write stamp + banners for a pair
python scripts/i18n.py --audit              # list docs without a twin (review exemptions)
```

`tests/test_i18n.py` enforces `--check`/`--links` on the repository.

## Workflow when editing / 修改流程

1. Edit the Chinese source `X.zh.md` (authoritative).
2. Update the English `X.md` to match.
3. Run `python scripts/i18n.py --finalize X.md` and commit both files together.

## Scope & exemptions / 范围与豁免

**Translated set**: `README`, `AGENTS`, all of `skills/auto-epublizer/**`, and all of
`docs/**` (see the plan `docs/plans/2026-09-18-i18n-english-docs.md`, appendix A).

**Exempt (Chinese-only or untouched)**: `docs/plans/**` (historical working notes),
`template/**` (generated workspace files), `THIRD_PARTY_LICENSES.md`, `LICENSE`,
`config.example.yaml`, `参考/**`, `dist/**`. CLI output, `--help` text, code comments
and domain naming stay Chinese by design.
